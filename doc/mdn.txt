1. INTRODUCTION                                              *mdn-intro*

mdn.nvim is a minimal Neovim plugin for Markdown editing that provides
smart list continuation and checkbox toggling.

It's deliberately small — no wikilinks, no tables, no ToC. Just the two
things you miss most when editing Markdown in Neovim.

==============================================================================
2. FEATURES                                                *mdn-features*

- Smart list continuation on <CR>, o, and O
  - Unordered lists (-, *, +) continue with the same marker
  - Ordered lists (1., 2), ...) auto-increment the number
  - Task lists (- [ ]) continue with empty checkboxes
  - Empty list items terminate continuation
  - Works with indented/nested lists

- Checkbox toggling
  - Toggle [ ] ↔ [x] in Normal mode via |:Mdn| toggle or keymap
  - Toggle [ ] ↔ [x] in Insert mode via keymap
  - Add [ ] to list items that don't have one

==============================================================================
3. REQUIREMENTS                                        *mdn-requirements*

- Neovim ≥ 0.10
- Markdown filetype (set automatically by Neovim for .md files)

  require("mdn").setup()
<

5. CONFIGURATION                                            *mdn-config*

mdn.setup({opts}) ~

The `mdn.setup()` function configures the plugin with user-provided options.

DEFAULT CONFIGURATION ~
>
  require("mdn").setup({
    auto_continue = true,
    keymaps = {
      toggle_checkbox = "<leader>x",
      toggle_checkbox_insert = "<C-Space>",
    },
  })
<

OPTIONS ~
>
  auto_continue    (boolean, default: true)
    Automatically continue lists when pressing <CR>, o, or O in
    Markdown buffers. Set to false to disable list continuation.

  keymaps          (table)
    Keymap configuration. Set individual keys to "" to disable.

    keymaps.toggle_checkbox         (string, default: "<leader>x")
      Normal mode key for toggling checkboxes.

    keymaps.toggle_checkbox_insert  (string, default: "<C-Space>")
      Insert mode key for toggling checkboxes.
<

==============================================================================
6. COMMANDS                                                *mdn-commands*

:Mdn toggle ~
    Toggle the checkbox on the current line.
    [ ] becomes [x], [x] becomes [ ].
    If the line is a list item without a checkbox, a [ ] is added.

==============================================================================
7. KEYMAPS                                                  *mdn-keymaps*

All keymaps are buffer-local to Markdown buffers (ftplugin/markdown.lua).
They are set up automatically when |mdn.setup()| is called.

LIST CONTINUATION (when auto_continue = true) ~
>
  <CR> (Insert mode)    Continue list below, enter Insert mode
  o    (Normal mode)    Continue list below, enter Insert mode
  O    (Normal mode)    Continue list above, enter Insert mode
<

CHECKBOX TOGGLE ~
>
  <leader>x   (Normal mode)    Toggle checkbox on current line
  <C-Space>   (Insert mode)    Toggle checkbox on current line
<

You can also use |<Plug>| mappings:
>
  vim.keymap.set("n", "<Plug>(MdnToggleCheckbox)", "<cmd>Mdn toggle<CR>")
<

8. API                                                          *mdn-api*

Public functions available after |mdn.setup()|:

                                                                 *mdn.setup()*
mdn.setup({opts}) ~
    Configure and enable the plugin. See |mdn-config| for options.

                                                          *mdn.toggle_checkbox()*
mdn.toggle_checkbox() ~
    Toggle the checkbox on the current line. Same as |:Mdn| toggle.

                                                           *mdn.continue_list()*
mdn.continue_list() ~
    Insert a new list item below the current line. Same as the `o` keymap.

                                                     *mdn.continue_list_above()*
mdn.continue_list_above() ~
    Insert a new list item above the current line. Same as the `O` keymap.

                                                      *mdn.continue_list_enter()*
mdn.continue_list_enter() ~
    Continue list on Enter (for Insert mode <CR> remap).
