1. INTRODUCTION                                              *mdn-intro*

mdn.nvim is a minimal Neovim plugin for Markdown editing that provides
smart list continuation and a bullet/checkbox cycle.

It's deliberately small — no wikilinks, no tables, no ToC. Just the
things you miss most when editing Markdown in Neovim.

==============================================================================
2. FEATURES                                                *mdn-features*

- Smart list continuation on <CR>, o, and O
  - Unordered lists (-, *, +) continue with the same marker
  - Ordered lists (1., 2), ...) auto-increment the number
  - Task lists (- [ ]) continue with empty checkboxes
  - Empty list items terminate continuation
  - Works with indented/nested lists

- Bullet/checkbox cycle on <C-CR>
  - 1. Blank/non-list line → creates bullet (uses configured bullet_marker)
  - 2. Bullet exists → adds "[ ] " after marker
  - 3. [ ] → [~] (unchecked → in progress)
  - 4. [~] → [x] (in progress → done)
  - 5. [x] → plain bullet (done → cycle restarts); other checkbox
    chars → [x]
  - Same key works in both Normal and Insert mode

- Concealed list and checkbox markers
  - Unordered list markers display as the configured listitem symbol
  - [ ], [x]/[X], [~], [>], [<], [o], and [-] display as their configured symbols
  - Checkbox lines replace the complete `- [state]` prefix with one symbol
  - Symbols include two spaces before the item text
  - The Markdown source remains unchanged
  - Virtual symbols remain visible with 'conceallevel' set to 3
  - Virtual symbols are hidden on the cursor line for editing

For insert-mode line indent/outdent, use Neovim's built-in |i_CTRL-T| and
|i_CTRL-D|.

5. CONFIGURATION                                            *mdn-config*

mdn.setup({opts}) ~

The `mdn.setup()` function configures the plugin with user-provided options.

DEFAULT CONFIGURATION ~
>
  require("mdn").setup({
    lists = {
      auto_continue = true,
      bullet_marker = "-",
    },
    mappings = {
      cycle_key = "<C-CR>",
    },
    conceal = {
      listitem = { pattern = "[-+*]%s", replace = " " },
      unchecked = { pattern = "%[%s%]%s", replace = "󰄱 " },
      checked = { pattern = "%[[xX]%]%s", replace = "󰄲 " },
      partial = { pattern = "%[~%]%s", replace = "󰡖 " },
      defer = { pattern = "%[>%]%s", replace = "󰁔 " },
      scheduled = { pattern = "%[<%]%s", replace = "󰃰 " },
      event = { pattern = "%[o%]%s", replace = "󰃭 " },
      canceled = { pattern = "%[%-]%s", replace = "󱋭 " },
    },
  })
<

OPTIONS ~
>
  lists.auto_continue    (boolean, default: true)
    Automatically continue lists when pressing <CR>, o, or O in
    Markdown buffers. Set to false to disable list continuation.

  lists.bullet_marker    (string, default: "-")
    List marker character used when the cycle key creates a new
    bullet from a blank or non-list line. Accepted values: "-",
    "*", "+".

  mappings.cycle_key     (string, default: "<C-CR>")
    Key for the bullet/checkbox cycle in both Normal
    and Insert mode. Set to "" to disable.

  conceal.<state>        (table)
    Rule for a list marker or checkbox state. Each rule contains:

    pattern (string)
      Lua pattern matched at the relevant source token.

    replace (string)
      Text displayed in place of the match, including any spacing.

    Defaults:
      listitem  pattern "[-+*]%s", replace " "
      unchecked pattern "%[%s%]%s", replace "󰄱 "
      checked   pattern "%[[xX]%]%s", replace "󰄲 "
      partial   pattern "%[~%]%s", replace "󰡖 "
      defer     pattern "%[>%]%s", replace "󰁔 "
      scheduled pattern "%[<%]%s", replace "󰃰 "
      event     pattern "%[o%]%s", replace "󰃭 "
      canceled  pattern "%[%-]%s", replace "󱋭 "

    The defaults use current nf-md Nerd Font glyphs. A Nerd Font is
    required to display them; each rule can be replaced.
<

CYCLING EXAMPLE ~
>
  (blank line)    <C-CR>  →  "- " (or configured bullet_marker)
  "- buy milk"     <C-CR>  →  "- [ ] buy milk"
  "- [ ] buy milk"  <C-CR>  →  "- [~] buy milk"
  "- [~] buy milk"  <C-CR>  →  "- [x] buy milk"
  "- [x] buy milk"  <C-CR>  →  "- buy milk"
<

6. COMMANDS                                                *mdn-commands*

:Mdn toggle ~
    Toggle the checkbox on the current line (or add one if it's a list
    item without a checkbox). Unlike the keymap cycle, this does NOT
    create bullet points from blank lines.

    Accepts a range: select lines in Visual mode and run
    `:'<,'>Mdn toggle`. When given a range, uses a uniform decision —
    if any checkbox is unchecked, all get checked; if all are checked,
    all get unchecked. Lines without an existing checkbox are skipped.

7. KEYMAPS                                                  *mdn-keymaps*

All keymaps are buffer-local to Markdown buffers. They are set up
automatically when |mdn.setup()| is called.

LIST CONTINUATION (when auto_continue = true) ~
>
  <CR> (Insert mode)    Continue list below, enter Insert mode
  o    (Normal mode)    Continue list below, enter Insert mode
  O    (Normal mode)    Continue list above, enter Insert mode
<

CHECKBOX CYCLE ~
>
  <C-CR>  (Normal + Insert)  Bullet/checkbox cycle:
    blank → bullet → [ ] → [~] → [x] → bullet
  <C-CR>  (Visual)           Toggle checkboxes across selected lines
<

8. API                                                          *mdn-api*

Public functions available after |mdn.setup()|:

                                                                 *mdn.setup()*
mdn.setup({opts}) ~
    Configure and enable the plugin. See |mdn-config| for options.

                                                                   *mdn.cycle()*
mdn.cycle() ~
    Run the bullet/checkbox cycle on the current line. Works in both
    Normal and Insert mode.

                                                          *mdn.toggle_checkbox()*
mdn.toggle_checkbox() ~
    Toggle the checkbox on the current line (or add one). Same as
    |:Mdn| toggle. Does not create bullet points.

                                                           *mdn.continue_list()*
mdn.continue_list() ~
    Insert a new list item below the current line.

                                                     *mdn.continue_list_above()*
mdn.continue_list_above() ~
    Insert a new list item above the current line.

                                                      *mdn.continue_list_enter()*
mdn.continue_list_enter() ~
    Continue list on Enter (for Insert mode <CR> remap).
